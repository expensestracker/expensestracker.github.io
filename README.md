## 📖 Overview

Hisapbook is a digital ledger designed to help users track their daily income and expenses, manage accounts, and gain insights into their financial habits. Built with performance and user experience in mind, it provides a clean interface for maintaining accurate financial records on the go.

## ✨ Features

* **Dashboard Overview:** Get a bird's-eye view of your current balance, total income, and total expenses.
* **Transaction Tracking:** Easily add, edit, or delete daily income and expense entries.
* **Categorization:** Group transactions by customizable categories (e.g., Groceries, Rent, Salary).
* **Data Visualization:** View spending habits over time with interactive charts.
* **Responsive Design:** Fully optimized for both desktop and mobile viewing.
* **Secure Authentication:** Secure user login and data protection.
